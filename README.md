# صور المعاملات PRO — Android

نسخة Android احترافية مستوحاة من واجهة الصورة المرفقة، مكتوبة بـ Kotlin + Jetpack Compose.

## المزايا المضمنة
- واجهة عربية RTL داكنة مطابقة لفكرة التصميم المرجعي.
- التقاط صورة بالكاميرا.
- اختيار صورة من المعرض.
- قياسات 6×4 سم، 4.5×3.5 سم، 5×5 سم.
- تجهيز الصورة بأبعاد بكسلية محسوبة لطباعة 300 DPI.
- قص مركزي تلقائي حسب المقاس.
- استبدال الخلفية بالأبيض أو الأزرق الفاتح أو الرمادي.
- خيار إزالة خلفية محلي بسيط مناسب للخلفيات الموحدة والفاتحة.
- حفظ الصور داخل مجلد Pictures/صور المعاملات PRO.
- سجل محلي لآخر الصور المحفوظة.

## فتح المشروع
1. افتح مجلد المشروع في Android Studio حديث.
2. انتظر Gradle Sync.
3. شغّل التطبيق على جهاز Android أو Emulator.

## ملاحظة تقنية
إزالة الخلفية الحالية تعتمد على خوارزمية محلية خفيفة تعتمد على لون الحواف، وليست نموذج Segmentation عميقاً. صُممت لتكون أول نسخة عملية تعمل بدون خدمة سحابية، ويمكن استبدالها لاحقاً بمحرك segmentation احترافي لنتائج أدق مع الشعر والخلفيات المعقدة.

## البناء
المشروع مضبوط لـ compileSdk 35 و targetSdk 35. بيئة المحادثة الحالية لا تتضمن Android SDK، لذلك لم أرفق APK مبنياً؛ المشروع المصدر جاهز للبناء داخل Android Studio.
